# Projects

Conway's Way of Life
Conway's Game of Life is a cellular automaton on a 2d grid which evolves over time. Its evolution is determined by its starting state. In this version, the starting configuration is a structure known as a Gosper's Glider Gun which infinitely shoots gliders southeast.

Password Manager
Python program paired with a csv (Comma Separated Values) file to simulate a password manager and database. Users can store, retrieve, delete, replace passwords and use the provided encryption and decryption mechanisms as well.
