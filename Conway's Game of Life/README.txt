Conway's Game of Life is a cellular automaton on a 2d grid which evolves over time. Its evolution is determined by its starting state. In this version, the starting configuration is a structure known as a Gosper's Glider Gun which infinitely shoots gliders southeast. 

Rules for Conway's Game of Life:

 'O' represents an alive cell.
Any live cell with fewer than two live neighbours dies
Any live cell with two or three live neighbours stays alive to the next phase
Any live cell with more than three live neighbours dies
Any dead cell with exactly three live neighbours becomes alive
